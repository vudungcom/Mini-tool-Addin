2. DESCRIPTION OF SOFTWARE
Mini Tool Add-in for Autodesk Inventor provides the following features:
  - Open CAD: Opens the corresponding CAD drawing file for the active
    Inventor document.
  - BOM Format: Applies BOM customization from a user-defined XML file.
  - Name Update: Updates display names of parts and occurrences from
    their file names.
  - Save IDW: Saves the drawing file (.idw) to the same folder as the
    referenced model file.
  - Check Reference: Scans assemblies for occurrences with BOM
    Structure set to Reference.
